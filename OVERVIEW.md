August Kanagawa Theme adds **August - Kanagawa (Darker)** to Paseo's app themes. It adapts the August Themes palette for VS Code, with a near-black background, warm off-white text and muted blue accents.

Requires Paseo 0.12.x with plugins enabled on the host. Select the theme under Settings → Appearance. The palette colors the app surfaces, terminal, diffs and status indicators through Paseo's native theme system. Code highlighting remains controlled by the separate Highlight theme setting; this plugin does not reproduce every VS Code syntax color. Font family and size are also separate app preferences and are not changed by the plugin.

The plugin only registers a color palette. It does not read files, start processes, make network requests or require accounts, credentials or additional software.
